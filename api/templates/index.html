Didukung oleh OpenRouter API & Supabase Database. Siap dideploy ke Vercel.

Panduan Konfigurasi & Setup

1. Kunci API OpenRouter

Dapatkan API Key secara gratis di openrouter.ai/keys. Masukkan ke file .env:

OPENROUTER_API_KEY=sk-or-v1-kunci-anda...

2. Database Supabase

Buat project gratis di supabase.com. Eksekusi file supabase_schema.sql di SQL Editor Supabase, lalu masukkan variabel ke .env:

SUPABASE_URL=https://proyek-anda.supabase.co
SUPABASE_KEY=anon-key-anda...

3. Deploy ke Vercel

Push proyek ke GitHub, import di dashboard Vercel, dan masukkan variabel lingkungan di menu Settings > Environment Variables Vercel.
