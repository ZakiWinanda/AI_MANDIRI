Panduan Konfigurasi

1. OpenRouter API Key

Dapatkan API Key gratis di openrouter.ai/keys. Masukkan ke .env:

OPENROUTER_API_KEY=sk-or-v1-xxx

2. Database Supabase

Buat project di supabase.com, jalankan supabase_schema.sql, lalu isi:

SUPABASE_URL=https://xxx.supabase.co
SUPABASE_KEY=eyJ...

3. Deploy ke Vercel

Push ke GitHub → Import di Vercel → tambahkan Environment Variables.
